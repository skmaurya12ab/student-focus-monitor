# Machine Learning Workspace

This directory is reserved for future machine learning workflows (Phases 11–14).

## Planned Architecture

- **`data/`**: Anonymized numerical movement telemetry datasets collected during study sessions.
- **`notebooks/`**: Exploratory data analysis, baseline experiments, and model prototyping.
- **`src/`**: Feature extraction pipelines, dataset generators, and training modules.
- **`models/`**: Serialized model artifacts and checkpoints.
- **`evaluation/`**: Validation scripts, confusion matrices, and benchmark reports.
- **`scripts/`**: Utility scripts for data pre-processing and model export.

> **Phase 1 Notice:** No ML models, datasets, or heavy frameworks (e.g. PyTorch, TensorFlow) are implemented in Phase 1. This folder provides the structural foundation for future phases.
